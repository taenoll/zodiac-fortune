# ☾ 오늘의 별자리 운세 ✦

생년월일을 고르면 별자리를 찾아 오늘의 운세를 보여 주는 작은 웹페이지예요.

- 오늘의 바이브(총운) · 애정운 · 금전운 · 학업운 · 에너지 지수 · 오늘의 솔루션
- 같은 날 같은 별자리는 항상 같은 결과 (날짜 + 별자리 + 항목 해시)
- HTML · CSS · JavaScript만 사용, 모바일 우선 (최대 너비 480px)
- 폰트: Jua, Gowun Dodum (Google Fonts)

## 실행

`index.html`을 브라우저로 열거나 Live Server로 실행하세요.

> 운세는 재미로 봐 주세요! ☆
